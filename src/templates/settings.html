Connection

For Azure DNS, leave Target DNS Server blank. For Microsoft or BIND, set the server that accepts updates (primary or allowed secondary).

Credentials

Microsoft (WinRM): domain account with rights to manage DNS on the server (for example CORP\dnsadmin). BIND (TSIG): key name from named.conf and the shared secret in base64 (same encoding as in the key statement).

Azure DNS (service principal)

Used only when DNS server type is Azure DNS. Values are stored encrypted in the database.
