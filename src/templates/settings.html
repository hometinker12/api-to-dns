{% elif selected_system_section == "syslog_forwarding" %}

Remote Syslog

Optionally forward stored audit/activity events to a remote syslog server as RFC 5424 messages with a JSON payload. Delivery is best-effort over UDP or TCP and never blocks API requests. Failed or dropped deliveries are recorded only in operational logs.

The in-process queue is non-durable. When the queue is full or the remote server is unavailable, events are dropped and a rate-limited warning is written to operational logs.
